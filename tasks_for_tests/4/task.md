## Делители чисел

Для каждого натурального числа в промежутке от M до N вывести все делители,
кроме единицы и самого числа. Значения M и N вводятся с клавиатуры

__Пример__

| Входные данные | Выходные данные |
|----------------|-----------------|
| 8 11           | 8: 2 4          |
|                | 9: 3            |
|                | 10: 2 5         |
|                | 11: простое     |
