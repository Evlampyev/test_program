## Найти номер второго элемента, кратного 5.
Список задаётся одной строкой. Вывести номер второго элемента кратного 5. Если его нет, то вывести -1

        <td>Список целых чисел одной строкой</td>
        <td style="vertical-align: top">Одно целое число</td>
    </tr>
</table>
