## Функции

Напишите функцию, которая находит сумму двух переданных ей чисел. На основе этой функции вычислите сумму всех введенных
чисел. Признаком окончания ввода является число 0.

### Пример

        <th><b><i>Входные данные</i></b></th>
        <th><b><i>Выходные данные</i></b></th>
    </tr>
    <tr>
        <td>20<br>15<br>25<br>0</td>
        <td style="vertical-align: top">60</td>
    </tr>
</table>
