## Элементы списка, равные первому
Найдите все индексы элементов списка, равные нулевому элементу. Список вводится одной строкой через запятую. Если таких нет, то выведете "НЕТ".
<table style="width: auto; margin: auto">
    <tr style="text-align: center">
        <th><b><i>Формат ввода</i></b></th>
        <th><b><i>Формат вывода</i></b></th>
    </tr>
    <tr style="vertical-align: top">
        <td>Строка чисел через запятую</td>
        <td style="vertical-align: top">Строка чисел через двоеточие</td>
    </tr>
</table>

### Пример
<table style="width: auto; margin: auto">
    <tr style="text-align: center">
        <th><b><i>Ввод</i></b></th>
        <th><b><i>Вывод</i></b></th>
    </tr>
    <tr style="vertical-align: top">
        <td>0,2,3,1,2,0,1,2,2,0</td>
        <td>5:9</td>
    </tr>
</table>
