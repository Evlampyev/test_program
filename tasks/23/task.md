## Функции: Расстояние между двумя точками

Составить функцию, которая вычисляет длину пути туристов, если их путь разбит на отрезки. Во входных данных в первой
строке количество отрезков n. Затем n+1 строк с координатами (x, y) точек.

    </tr>

        <td>В первой строке количество отрезков n.<br>
В следующих n+1 строках координаты точек x y</td>
        <td style="vertical-align: top">Число с точностью до двух знаков после запятой - длина пути</td>
    </tr>
