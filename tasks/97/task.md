## Операции с тремя числами
Написать программу, которая по трем введенным с клавиатуры числам выводит корень из суммы квадратов, корень из разности квадратов (использовать модуль), корень из произведения квадратов и корень из частного квадратов, корень из средних арифметических квадратов этих чисел. В ответе числа должны содержать ровно три знака после запятой.
<table style="width: auto; margin: auto">
    <tr style="text-align: center">
        <th><b><i>Формат ввода</i></b></th>
        <th><b><i>Формат вывода</i></b></th>
    </tr>
    <tr style="vertical-align: top">
        <td>Три целых числа через пробел</td>
        <td style="vertical-align: top">Пять строк данных с результатами вычислений, округленные до трёх знаков после запятой</td>
    </tr>
</table>

### Пример
<table style="width: auto; margin: auto">

корень из произведения квадратов = 210.0<br>
корень из квадрата произведения = 210.0<br>
корень из среднего арифметического квадратов = 9.626
</td>
    </tr>
</table>
