## Сумма элементов списка с индексами с 'k' по 'n'.
С клавиатуры вводится целое n - количество элементов списка. Далее вводится n элементов (целые числа), каждый в отдельной строке. Затем в одной строке вводятся два целых числа это индексы 'k' и 'n'. Необходимо вывести сумму элементов списка  с индексами от 'k' до 'n' включительно. Какое из чисел k и n меньше, а какое больше  - не известно.

    </tr>
    <tr style="vertical-align: top">
        <td>Количество элементов списка<br>Элементы списка<br>k и n в одной строке через запятую</td>
        <td style="vertical-align: top">Сумма элементов от k до n </td>
    </tr>
</table>
