О платформе

Платформа для обучения программированию — это современная образовательная среда, разработанная для эффективного обучения школьников основам программирования и алгоритмизации.

Наш проект создан с целью предоставить учителям и ученикам удобный инструмент для изучения программирования, автоматической проверки решений и отслеживания прогресса. Платформа поддерживает структурированное обучение по классам, темам и уровням сложности.

Для учителей

Управление классами и группами, создание задач, просмотр статистики учеников

Для учеников

Доступ к задачам по уровням, автоматическая проверка решений, рейтинг

Возможности платформы

Создание задач

Учителя могут создавать новые задачи с описанием, эталонным решением и тестами. Все задачи автоматически структурируются по классам и уровням.

Проверка решений

Автоматическая проверка кода учеников с помощью тестов. Мгновенный результат и обратная связь.

Управление группами

Учителя видят только своих учеников. Возможно разделение класса на группы с разными учителями.

Статистика

Детальная статистика по каждому ученику: количество решенных задач, успешность попыток, прогресс.

Рейтинги

Внутригрупповые рейтинги учеников для мотивации и отслеживания успеваемости.

Безопасность

Разграничение доступа: ученики видят только свои задачи, учителя - только своих учеников.
